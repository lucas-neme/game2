# Publicação independente — /game2/
No servidor Wampa, clone o repositório, execute docker compose up -d --build e confirme curl -f http://127.0.0.1:8092/game2/. A porta 8092 é uma sugestão: confirme que está livre antes de subir. Integre wampa-location.conf ao virtual host HTTPS existente, valide nginx -t e recarregue o proxy. Se o proxy estiver em container, conecte ambos à mesma rede e substitua 127.0.0.1:8092 pelo nome do serviço game2:80. Não substitua as rotas existentes. Verifique https://wampa.com.br/game2/ e os SVGs. O jogo é estático, não requer Vanguarda, banco de dados ou credenciais; o progresso fica no navegador. Execute node tests/demo-smoke.mjs e o teste Chromium no CI. Não declare publicação antes de validar HTTP e jogar a demo.
